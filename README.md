# 喵布布的復仇 | MeowBuBu's Revenge

像素風橫向動作平台 HTML5 遊戲。  
喵布布的魚被偷了，決定展開一連串復仇之旅！

## 遊玩

用本機伺服器開啟（勿直接雙擊 `index.html`，部分瀏覽器會擋本地資源）：

```bash
node server.js
```

然後開啟：http://localhost:5500

## 操作

| 按鍵 | 功能 |
|------|------|
| ← → / A D | 移動 |
| ↑ / W / 空白 | 跳躍 |
| ↓ / S | 向下瞄準 |
| Z / J | 近戰攻擊 |
| X / C / F | 技能（可搭配方向八向射擊） |
| V / Q / R / U | 大絕招「魚影・復仇風暴」 |
| Shift | 奔跑 |
| H / P | 開關**自動掛機模式** |

觸控裝置可用螢幕虛擬搖桿與按鈕。

### 自動掛機模式

- **標題畫面**按 `H` 或 `P`：跳過序章，直接開局並啟用掛機
- **遊戲中**按 `H` / `P`：隨時開關掛機（手動操作仍可覆蓋 AI）
- 掛機會自動移動、攻擊、放技能／大絕、撿愛心與魚、推進關卡與打 Boss
- 通關或死亡後會自動從第 1 關再來（LOOP 計數顯示於右上角）

## 遊戲內容

- 序言劇情
- 關卡 1 森林 → 關卡 2 城堡 → Boss「魚怪大盜」
- 踩踏敵人、補血愛心、大絕蓄力
- 自動掛機模式

## 技術

- 純 HTML5 Canvas + JavaScript（無框架）
- 素材位於 `assets/sprites`、`assets/bg`
